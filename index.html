Live Pest Detection (Webcam)

The built-in COCO-SSD model detects general objects, not crop pests. For pest labels, connect a separately trained crop model. Results are experimental and must be verified.

Remote setup: run the included app.py server, select Remote model, and enter its /api/detect URL. Photos are sent to that URL only when you start detection or submit a photo. The default server model is generic; crop-pest recognition needs custom-trained weights.
